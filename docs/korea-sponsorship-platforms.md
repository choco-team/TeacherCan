# 한국 후원 플랫폼 조사

- 작성일: 2026-08-26
- 목적: TeacherCan에 후원 시스템을 도입하기 위한 후보 플랫폼 조사
- 범위: 한국에서 실제로 쓸 수 있는 공익 기부, 크리에이터 후원, 크라우드펀딩, 자체 결제, 간편송금
- 주의: 수수료·자격·정책은 수시로 바뀝니다. 도입 직전에 각 공식 페이지에서 다시 확인하세요. 세금·기부금품법 해석은 법률 자문이 아닙니다.

---

## 1. TeacherCan에 맞는 후원이란

TeacherCan은 한국 교사가 수업 중에 바로 쓰는 무료 웹 도구입니다. 후원 사용자는 스트리머 시청자가 아니라, 카카오페이·토스·네이버페이에 익숙한 교사입니다.

그래서 플랫폼을 고를 때 수수료만 보면 안 됩니다. 아래 기준이 더 중요합니다.

| 기준 | 왜 중요한가 |
| --- | --- |
| 한국어·원화 | 교사가 환전·해외카드 없이 결제해야 함 |
| 카카오페이·토스·카드 | 교사 결제 습관과 맞아야 전환율이 나옴 |
| 사업자 없이 시작 가능 | 바로 실험할 수 있어야 함 |
| 일회성 + 정기후원 | 서버비는 매달 나가므로 정기가 이상적 |
| 사이트에 붙이기 쉬움 | 헤더/랜딩의 "후원하기" 한 버튼이면 충분 |
| 기부금영수증 | 교사는 연말정산을 중시함. 없으면 전환이 떨어질 수 있음 |
| 브랜딩 | "별풍선 후원" 느낌이 나면 학교 서비스와 안 맞음 |

핵심 결론부터 말하면, 해피빈·같이가치 같은 공익 기부 플랫폼은 지금 단계의 TeacherCan에 맞지 않습니다. 비영리 법인과 기부금영수증 자격이 필요하기 때문입니다. 현실적인 1차는 **국내 크리에이터 후원 플랫폼** 또는 **간편송금**, 중기는 **자체 PG 결제**, 특정 기능을 크게 만들 때는 **크라우드펀딩**입니다.

## 2. 후원 모델을 먼저 구분하기

한국에는 "후원"이라는 말 아래 성격이 다른 시장이 섞여 있습니다. 플랫폼을 나열하기 전에 모델을 나눠야 비교가 됩니다.

| 모델 | 한 줄 정의 | 대표 사례 | TeacherCan 적합성 |
| --- | --- | --- | --- |
| 공익 기부 | 검증된 비영리 단체에 기부. 영수증 발급 | 해피빈, 카카오같이가치 | 낮음. 법인·자격 필요 |
| 크리에이터 후원 | 개인/팀이 응원금을 받음 | 크티, 리틀리 | 높음. 바로 시작 가능 |
| 멤버십/구독 | 매달 내고 혜택을 받음 | 크티, 패트리온, 그로블 | 높음. 서버비와 잘 맞음 |
| 크라우드펀딩 | 기간 한정 캠페인, 리워드 제공 | 와디즈, 텀블벅 | 중간. 기능 출시용 |
| 자체 PG 결제 | 사이트 안에서 직접 결제 | 토스페이먼츠, 페이플 | 중기. 사업자 필요 |
| 간편송금 | 카카오페이/토스로 직접 보내기 | 송금코드, 토스 링크 | 높음. 실험용 |
| 방송 도네이션 | 라이브 알림, TTS, 룰렛 | 투네이션, 팬플 | 매우 낮음 |
| 오픈소스 후원 | 개발자 대상으로 GitHub에서 후원 | GitHub Sponsors | 보조. 교사 유입은 약함 |

TeacherCan은 "무료 교육 도구를 계속 운영하게 해주세요"에 가깝습니다. 라이브 방송 후원도, 공익 모금함도 아닙니다.

## 3. 법·세금에서 알아둘 점

후원 버튼을 달기 전에 이 세 가지는 구분해 두는 것이 좋습니다.

### 3.1 기부금품법

- 반대급부 없이 불특정 다수에게 돈을 모아 달라고 권유하면 기부금품 모집에 해당할 수 있습니다.
- 1천만 원 이상을 목표로 공개 모금하면 행정 등록이 필요합니다.
- 영리 목적 모금은 등록 대상이 아니거나, 반대로 등록 자체가 불가능할 수 있습니다.
- 콘텐츠·서비스 제공의 대가(멤버십, 리워드, 후원자 명단, 얼리 액세스)로 받으면 기부가 아니라 매출에 가깝습니다.

실무적으로는 **"대가 없는 순수 기부"**보다 **"응원 멤버십 / 후원 리워드"**로 설계하는 편이 안전합니다. 감사 메시지, 후원자 이름 표시, 실험실 기능 우선 사용 같은 가벼운 혜택이면 충분합니다.

### 3.2 기부금영수증

교사가 가장 먼저 물을 수 있는 질문입니다. "연말정산 되나요?"

- 해피빈·같이가치는 지정기부금단체만 입점하므로 영수증이 나갑니다.
- 크티, 리틀리, 그로블, 카카오페이 송금은 **연말정산용 기부금영수증이 없습니다.**
- 사업자로 PG를 붙이면 현금영수증·세금계산서는 가능하지만, 이것도 기부금공제가 아닙니다.

TeacherCan이 비영리 법인이 되기 전에는 "후원은 서비스 운영 지원이며, 기부금공제 대상이 아닙니다"를 후원 페이지에 분명히 쓰는 것이 좋습니다.

### 3.3 소득 신고

개인으로 후원을 받으면 기타소득 또는 사업소득으로 신고 대상이 될 수 있습니다. 연 매출이 커지면 사업자등록 의무가 생길 수 있습니다. 플랫폼이 세금계산서·정산 엑셀을 주더라도, 신고 자체는 운영자 책임입니다.

## 4. 공익 기부 플랫폼

한국에서 가장 知名度가 높은 기부 채널입니다. 다만 **단체가 입점하는 곳**이지, 개인 서비스가 후원 링크를 여는 곳이 아닙니다.

### 4.1 네이버 해피빈

**특징**

- 네이버 계정·네이버페이·"콩(포인트)"으로 소액 기부를 쉽게 만듭니다.
- 플랫폼 수수료 0%. 결제 수수료도 네이버·재단이 부담하는 구조로 알려져 있습니다.
- 기부금영수증을 발급합니다.
- 모금함 단위로 목표액·기간·후기를 공개합니다.
- 누적 모금액이 매우 크고, 네이버 트래픽으로 신규 기부자를 만날 수 있습니다.

**개설 자격 (공식 가입 조건)**

- 설립·운영 3년 이상
- 비영리 법인 또는 단체 (사회복지법인, 사단/재단법인, 비영리민간단체, 사회적협동조합 등)
- 공익사업을 정관상 고유목적사업으로 명시
- 세제적격단체 (특례/일반 기부금단체, 즉 영수증 발급 가능)

**장점**

- 교사에게 "기부"로 인식되기 쉽고, 연말정산이 됩니다.
- 수수료 부담이 거의 없습니다.
- 네이버 검색·페이 사용자 유입이 있습니다.

**단점**

- TeacherCan 같은 웹 서비스/개인 프로젝트는 입점할 수 없습니다.
- 심사가 월 1회이고, 연말(11~1월)에는 심사를 하지 않습니다.
- 모금함마다 후기·사용 내역 공개 의무가 있습니다.
- 플랫폼 안에서 경쟁이 심해 소규모 단체는 노출이 어렵습니다.

**TeacherCan 판정:** 현재 자격 미달. 비영리 법인화 이후에나 검토.

### 4.2 카카오같이가치

**특징**

- 카카오톡·다음 트래픽을 쓰는 공익 모금 플랫폼입니다.
- 응원·댓글·공유만 해도 카카오가 100원씩 대신 기부하는 "같이기부"가 핵심입니다.
- 수수료는 카카오가 부담하고, 기부금은 단체에 100% 전달됩니다.
- 기부금영수증, 정기후원(매달기부), 카카오톡 선물하기 연동이 있습니다.
- 누구나 공익 프로젝트를 제안할 수 있지만, 실제 모금함 운영은 검증된 파트너·단체를 통합니다.

**장점**

- 카카오톡에 있는 교사에게 접근하기 쉽습니다.
- 응원만으로도 모금액이 쌓이는 독특한 모델입니다.
- 신뢰도와 브랜드가 높습니다.

**단점**

- 개인 웹 서비스가 직접 상시 후원 페이지를 열 수 없습니다.
- 사회적경제 영역(소셜벤처, 협동조합, 사회적기업 등)은 파트너 재단 공모를 통과해야 합니다.
- 캠페인형이라 상시 운영비 후원과는 결이 다릅니다.

**TeacherCan 판정:** 단기 부적합. 협동조합·사회적기업으로 전환한 뒤 공모 참여는 가능.

### 4.3 토스 기부 / 기타 포털 기부

토스, 네이버, 카카오페이에는 앱 안 기부 탭이 있습니다. 대부분 **이미 등록된 자선단체**에 기부하는 채널입니다. TeacherCan이 단체가 되기 전에는 입점 대상이 아닙니다.

## 5. 국내 크리에이터 후원·멤버십 플랫폼

사업자 없이 한국어·원화로 후원을 받을 수 있는 현실적인 1차 후보입니다.

### 5.1 크티 (CTEE)

한국형 크리에이터 상점입니다. 디지털 파일 판매 + 멤버십 + 후원 + 이벤트를 한 페이지에서 운영합니다.

**특징**

- 사업자 등록·입점 심사 없이 SNS 로그인으로 시작합니다.
- 후원: 플랫폼 수수료 0%, PG 수수료 약 3~4%
- 멤버십·상품: 플랫폼 수수료 약 11.5% + 국내 PG 3.18% (2024-06 이후 공식 안내)
- 후원 금액은 3,000 / 6,000 / 9,000원처럼 고정 단위
- 정산은 매월 1일·16일 자동 입금, 최소 출금액 없음
- 후원은 결제 즉시 확정, 환불 불가
- 해외 결제(USD/JPY) 지원, 원화 정산
- 후원 결제 수단은 **카드 위주**. 카카오페이는 완성형 상품에만 되고, 후원·멤버십에는 안 됩니다.

**장점**

- 후원만 보면 국내에서 가장 수수료가 낮습니다.
- 교사 대상 학습자료 마켓이 있어, 나중에 수업 자료를 팔 확장 여지가 있습니다.
- 개발 없이 링크만 붙이면 됩니다.
- 한국어 UI, 국내 고객센터, 정산 엑셀이 있습니다.

**단점**

- 후원/멤버십에서 카카오페이가 안 됩니다. 교사 전환율에 불리합니다.
- 후원 금액이 고정 단위라 5,000원·10,000원처럼 자유롭게 못 고릅니다.
- 상품·멤버십 수수료(약 11.5%)는 높은 편입니다.
- 구매자가 크티 가입을 해야 할 수 있습니다.
- 브랜딩이 크리에이터 상점이라, TeacherCan 사이트와 이질감이 날 수 있습니다.

**TeacherCan 판정:** 후원 수수료는 최상위. 다만 결제 수단이 카드라 **1순위라고 단정하기 어렵습니다.** 카카오페이 가능 여부를 도입 전에 반드시 재확인하세요.

### 5.2 리틀리 (Littly, litt.ly)

링크인바이오(소개 페이지)에 후원·판매 블록을 붙이는 국내 플랫폼입니다. 텔레그램·인스타 운영자에게 많이 쓰입니다.

**특징**

- 사업자 없이 후원하기/판매하기 블록을 켤 수 있습니다.
- 리틀리 이용료 기본 5% + PG 약 2.9% + VAT. 실효 약 8% 전후
- 누적 결제액이 늘면 이용료가 4% → 3% → 2%로 내려갑니다. (공식 안내: 1천만 / 1억 / 100억 원 구간. 마케팅 문구의 "최저 1%"와 공식 표가 다를 수 있으니 계약 시 확인)
- 정산은 매주 금요일 자동 입금
- 세금계산서 자동 발행
- 한 페이지에 링크, 후원, 상품을 같이 둘 수 있습니다.

**장점**

- 국내 결제·한국어·주 단위 정산이 빠릅니다.
- "후원하기" 블록이 있어서 모델이 명확합니다.
- 사업자 없이 시작 가능합니다.
- 소개 페이지를 후원 랜딩으로 바로 쓸 수 있습니다.

**단점**

- 크티 후원(PG만)보다 수수료가 높습니다.
- 발견(discovery)이 약해, 트래픽은 TeacherCan이 직접 보내야 합니다.
- 크리에이터/인플루언서 톤이라 교육 서비스 브랜드와 거리가 있습니다.
- 플랫폼 자체 블로그의 수수료 비교는 자사 홍보가 섞여 있습니다.

**TeacherCan 판정:** 빠르게 한국어 후원 페이지를 열기에 무난합니다. 수수료는 크티보다 높고, 그로블·래피드보다 "후원" 프레이밍이 분명합니다.

### 5.3 그로블 (Groble)

2025년 정식 출시한 링크 커머스입니다. 후원 전용은 아니지만, **사업자 없이 한국 간편결제 + 정기결제**가 됩니다.

**특징**

- 사업자·PG 계약 없이 결제 링크 생성
- 일반결제 총 4.4%, 정기결제 총 5.4% (VAT 별도) — 서비스 1.5~2.5% + PG 2.9%
- 카드, 카카오페이, 네이버페이, 할부, 1~12개월 정기결제
- 디지털 파일 자동 배송
- 정산 월 2~4회, 세금계산서·국세청 자료 제출 지원
- 국내 전용, 글로벌 결제 없음

**장점**

- 교사에게 익숙한 간편결제를 지원합니다.
- 정기후원(구독)을 월 고정비 없이 만들 수 있습니다.
- 수수료가 국내 후보 중 낮은 편입니다.
- "구매"로 설계하면 기부금품법 리스크를 줄일 수 있습니다.

**단점**

- 서비스 이력이 짧아 장기 안정성은 검증 중입니다.
- UI가 상점/상품 중심이라 "후원합니다"보다 "상품을 삽니다"에 가깝습니다.
- 순수 후원 메시지·응원 댓글 같은 기능은 약합니다.
- 통신판매업·사업자 의무는 매출이 커지면 따로 검토해야 합니다.

**TeacherCan 판정:** **정기후원 UX와 간편결제를 동시에 원할 때 유력 후보.** "월 5,000원 운영 후원 멤버십"처럼 상품화하면 잘 맞습니다.

### 5.4 래피드 (Latpeed)

그로블과 비슷한 비사업자 링크 결제입니다.

**특징**

- 가입 후 결제 링크를 바로 만듭니다.
- Free: 플랫폼 1.6% + PG 2.9% 수준, 기능 제한, 초기 월 한도 낮음(약 10만 원)
- Lite: 플랫폼 4.6% + PG
- Pro: 월 약 3만 원 + 플랫폼 1.6% + PG, 멤버십·정기결제
- 판매자 정보 등록 시 한도가 올라갑니다(약 100만 원)

**장점**

- 실험 비용이 거의 없습니다.
- 주 단위 정산이 빠릅니다.
- 그로블과 수수료가 비슷합니다.

**단점**

- 초기 판매 한도가 낮아 후원이 몰리면 막힐 수 있습니다.
- 후원 전용 기능이 아닙니다.
- 역시 서비스 브랜드가 교육과 거리가 있습니다.

**TeacherCan 판정:** MVP 검증용. 한도와 정기결제 조건을 보고 그로블과 비교하면 됩니다.

### 5.5 포스타입 (Postype)

글·웹툰·멤버십 창작 플랫폼입니다.

**특징**

- 포스트 판매·멤버십 정기후원 기본 수수료 13% (2025-05 이후)
- 검색·추천 유입 후 72시간 내 포스트 구매 시 디스커버리 수수료 17% 추가 (합 30%)
- 한국어 창작 커뮤니티가 있습니다.

**장점 / 단점**

- 글 중심 창작자에게는 발견 채널이 있습니다.
- TeacherCan은 글 매거진이 아니므로 사용자 동선이 맞지 않습니다.
- 수수료가 높습니다.

**TeacherCan 판정:** 제외.

## 6. 크라우드펀딩 (캠페인형)

상시 후원이 아니라, **"이 기능을 만들게요. 기간 안에 후원해주세요"**에 쓰는 도구입니다.

### 6.1 와디즈

**특징**

- 한국 최대 리워드 크라우드펀딩입니다.
- 2026-02-02부터 한국 메이커 단일 요금제: 서비스 이용 12% + 결제·정산 3% + 99,000원 (VAT 별도)
- 첫 펀딩 성공 시 서비스 이용 수수료 30% 할인
- 후원·팬덤 카테고리: 물건이 없어도 되고, 감사 메시지·결과 리포트 같은 가벼운 리워드면 됩니다.
- 개인이 후원·팬덤 프로젝트를 열면 2026-12-31까지 플랫폼 이용 수수료 90% 지원 캠페인이 있습니다.
- 목표 달성 여부에 따라 진행되는 All-or-nothing 성격이 강합니다.

**장점**

- 와디즈 트래픽으로 신규 사용자를 만날 수 있습니다.
- 스토리텔링("교사 도구를 계속 무료로")에 강합니다.
- 개인도 후원·팬덤으로 열 수 있습니다.
- 특정 기능(예: 공간 예약 고도화, 모바일 앱) 개발비를 한 번에 모으기 좋습니다.

**단점**

- 상시 후원이 아닙니다. 캠페인이 끝나면 끊깁니다.
- 페이지 작성, 리워드 발송, 소통 비용이 큽니다.
- 실패하면 모금액이 0이 될 수 있습니다.
- 일반 펀딩 수수료는 높은 편입니다. 개인 후원·팬덤 할인 기간을 꼭 확인해야 합니다.
- 리워드를 약속하면 이행 책임이 생깁니다.

**TeacherCan 판정:** 상시 후원 대신, **"큰 기능 하나"를 만들 때** 쓰는 2차 채널.

### 6.2 텀블벅

**특징**

- 창작·문화 프로젝트에 강한 펀딩 플랫폼입니다.
- 성공 시에만 수수료. 실패하면 면제
- 요금제: Start 5% / Run 9% / Boost 15% + 결제 대행 3% (모두 VAT 별도)
- 개인 창작자 친화적, 후원자 커뮤니티가 있습니다.

**장점**

- Start 요금제는 와디즈 일반 요금보다 플랫폼 수수료가 낮습니다.
- 교육·창작 스토리와 톤이 잘 맞습니다.
- 후원자 관리 도구가 있습니다.

**단점**

- 와디즈보다 생활용품/테크 트래픽은 적고, 창작 팬덤 트래픽이 많습니다.
- 역시 캠페인형이라 상시 운영비와는 다릅니다.
- 리워드 제작·발송 부담이 있습니다.

**TeacherCan 판정:** "교사와 함께 만드는 다음 도구" 캠페인에 와디즈보다 톤이 맞을 수 있습니다. 수수료는 Start 기준이 유리합니다.

## 7. 해외 크리에이터 플랫폼 (한국에서 쓸 수는 있음)

한국어 교사 대상이면 주력으로 쓰기 어렵습니다. 결제 마찰이 큽니다.

### 7.1 패트리온 (Patreon)

**특징**

- 세계적으로 가장 유명한 정기후원/멤버십 플랫폼
- 2025-08-04 이후 신규 크리에이터 플랫폼 수수료 10% + 결제 수수료 별도
- iOS 앱 결제 시 애플 수수료가 추가로 붙을 수 있음
- 티어, Discord 연동, 멤버 전용 포스트가 강점

**장점**

- 멤버십 운영 노하우·기능이 가장 성숙합니다.
- 해외 사용자에게는 신뢰가 있습니다.

**단점**

- USD 중심, 한국어·원화 경험이 약합니다.
- 한국 카드 해외결제 거부, 환전 수수료가 흔합니다.
- 교사가 가입·결제하는 허들이 높습니다.
- 세금은 해외 소득처럼 처리해야 할 수 있습니다.

**TeacherCan 판정:** 주력 제외. 해외 교사 유입이 생길 때만 보조.

### 7.2 Ko-fi

**특징**

- "커피 한 잔" 일회성 팁 + 멤버십 + 상점
- 결제 처리: PayPal 또는 Stripe. Ko-fi는 돈을 들고 있지 않고 바로 정산
- 공식 가격: 서비스 수수료 최대 5% + 결제 수수료. 예전에는 후원 0% 마케팅이 많았으나, 2026 공식 가격 페이지는 5%로 안내합니다. 도입 시 현재 플랜을 재확인하세요.

**장점**

- 설정이 단순하고, 일회성 후원 UX가 좋습니다.
- 글로벌에서 인지도가 있습니다.

**단점**

- Stripe/PayPal이 한국 사업자·개인에게 불편합니다.
- 한국어·카카오페이가 없습니다.
- 교사 결제 전환이 낮을 가능성이 큽니다.

**TeacherCan 판정:** 주력 제외.

### 7.3 Buy Me a Coffee

**특징**

- 일회성 팁 + 멤버십
- 플랫폼 수수료 5% + Stripe 결제 수수료
- 한국이 지원 국가로 안내되는 경우가 있고, Stripe Express로 국내 계좌 정산을 시도한 사례가 있습니다.
- UI는 영어, 결제는 카드 번호 입력 중심

**장점**

- "커피 사주세요"가 직관적입니다.
- 위젯을 사이트에 붙이기 쉽습니다.

**단점**

- 카카오페이 없음, 한국어 약함
- Ko-fi와 마찬가지로 교사 UX가 나쁩니다.

**TeacherCan 판정:** 주력 제외.

### 7.4 GitHub Sponsors

**특징**

- 오픈소스 개발자/조직을 GitHub에서 후원
- 개인 계정 후원은 GitHub 수수료 0% (결제 처리 비용은 별도 구조)
- 조직 계정은 최대 6%
- 한국은 지원 지역에 포함된 적이 있으며, Stripe Connect로 계좌 지급
- 일회성·정기후원 모두 가능

**장점**

- 개발자 커뮤니티 신뢰가 높고, 수수료가 낮습니다.
- 레포에 Sponsor 버튼이 붙습니다.

**단점**

- 교사는 GitHub 계정이 없는 경우가 많습니다.
- 결제 UI가 개발자용입니다.
- TeacherCan 트래픽의 대부분이 웹 도구 사용자이지 GitHub 사용자가 아닙니다.

**TeacherCan 판정:** 오픈소스 기여자·개발자 후원용 보조 채널. 교사 후원의 주력은 아닙니다.

## 8. 자체 구축: PG로 사이트 안에 후원하기

사업자가 있고, TeacherCan UI 안에서 결제를 끝내고 싶을 때입니다. 중기 목표에 해당합니다.

### 8.1 토스페이먼츠

**특징 (공식 이용요금, VAT 별도)**

- 가입비 220,000원(최초), 연관리비 110,000원. 계약에 따라 다를 수 있음
- 신용·체크카드 일반 3.4%, 간편결제 3.4%(일부 추가), 계좌이체 2.0%
- 정산 평균 5일 이내, 보증보험 일정 한도 면제
- 자동결제(빌링)는 별도 계약·리스크 심사. 구독형 서비스가 아니면 제한될 수 있음
- 개발 문서와 DX가 국내 PG 중 좋은 편
- **사업자등록 필수. 개인(주민번호만)은 계약 불가**

**장점**

- 카카오페이·토스페이·카드를 TeacherCan 페이지에서 받을 수 있습니다.
- 플랫폼 수수료가 없어, 규모가 커지면 총비용이 가장 낮습니다.
- 브랜드·도메인을 유지합니다.
- 후원자 데이터·영수증·웹훅을 직접 설계할 수 있습니다.

**단점**

- 사업자, 통신판매업(해당 시), 심사가 필요합니다.
- 가입비·연관리비가 있습니다.
- 빌링(정기후원)은 추가 심사입니다. "후원"이 구독 상품으로 인정돼야 합니다.
- 결제 실패 재시도, 취소, 현금영수증을 직접 구현해야 합니다.
- 기부금영수증은 여전히 안 됩니다.

**TeacherCan 판정:** 후원이 검증된 뒤의 **본게임**. `/sponsor` 페이지를 직접 만드는 목표 지점입니다.

### 8.2 페이플 (Payple)

**특징**

- 스타트업·구독 SaaS에 강한 PG
- 카드 빌링 + 계좌 ARS 자동이체 + 해외카드 정기결제를 한곳에서 처리
- 멤버십(월 이용료) 플랜이 있는 것으로 안내됨. 상업 수수료는 계약형
- 사업자 필수, 심사 약 1영업일 수준이라는 안내가 있음
- 계약 전 테스트 연동이 가능

**장점**

- 정기후원에 필요한 빌링이 본업입니다.
- 계좌 자동이체는 카드한도가 없는 교사에게 유리할 수 있습니다.

**단점**

- 공개 수수료가 없어 견적을 받아야 합니다.
- 토스페이먼츠보다 브랜드 인지도는 낮습니다.
- 역시 사업자와 개발이 필요합니다.

**TeacherCan 판정:** 정기후원을 사이트에 붙일 때 토스페이먼츠와 견적 비교.

### 8.3 포트원 (구 아임포트)

**특징**

- 여러 PG를 한 API로 붙이는 결제 인프라
- 자체 수수료 없이 PG 수수료만 내는 구조로 알려져 있습니다.
- PG 전환·가입비 패키지 혜택이 있는 경우가 있습니다.

**장점**

- 나중에 PG를 바꿔도 코드 수정이 적습니다.
- 토스페이먼츠 단일 의존을 줄일 수 있습니다.

**단점**

- 레이어가 하나 더 생겨 디버깅이 복잡해질 수 있습니다.
- 초기에는 오버엔지니어링일 수 있습니다.

**TeacherCan 판정:** 첫 PG는 토스페이먼츠 직접 연동이 단순합니다. 멀티 PG가 필요해지면 검토.

## 9. 간편송금 (플랫폼이 아닌 후원)

가장 빠르고 수수료가 없는 방법입니다. 시스템은 약합니다.

### 9.1 카카오페이 송금 / 토스 송금 / 계좌이체

**특징**

- 송금코드, QR, 토스 아이디, 계좌번호를 사이트에 붙입니다.
- 개인 간 송금은 보통 수수료 0원입니다.
- 개발이 거의 필요 없습니다.

**장점**

- 교사가 가장 잘 아는 결제입니다.
- 5,000원을 보내면 5,000원이 들어옵니다.
- 오늘 바로 할 수 있습니다.

**단점**

- 누가, 얼마를, 왜 보냈는지 자동으로 모이지 않습니다.
- 감사 메일, 정기 후원, 영수증, 취소가 없습니다.
- 운영자 개인 계좌가 노출됩니다.
- 규모가 커지면 기부금품법·세무 이슈를 수동으로 관리해야 합니다.
- "후원 시스템"이라고 부르기 어렵습니다.

**TeacherCan 판정:** **이번 주 실험**에는 최선. 본 시스템으로는 부족합니다. 크티/리틀리/그로블과 병행하는 정도는 가능합니다.

## 10. 방송 후원 플랫폼 — TeacherCan에 맞지 않음

조사를 하다 보면 투네이션, 트윕, 팬플, 치지직 치즈, 유튜브 슈퍼챗이 많이 나옵니다. 한국 "후원" 검색의 대부분이 라이브 방송입니다.

| 플랫폼 | 한 줄 | 왜 제외하는가 |
| --- | --- | --- |
| 투네이션 | TTS, 알림, 룰렛. 결제수단별 수수료 편차 큼 | 수업 도구와 톤이 충돌 |
| 트윕 | 과거 양대 산맥. 서비스 변동/종료 언급이 있음 | 안정성·적합성 모두 낮음 |
| 팬플 | 투네이션 대안, 주 정산, OBS 위젯 | 스트리머용 |
| 치지직/SOOP/유튜브 | 플랫폼 내 후원, 수수료 20~40%대 | 방송 채널이 전제 |

TeacherCan 헤더에 "도네이션 알림"을 넣는 순간, 학교 현장에서 쓰기 불편해질 수 있습니다. 조사 대상으로만 기록하고 후보에서 빼는 것을 권합니다.

## 12. 플랫폼별 장단점 요약

### 공익 기부

- **해피빈 / 같이가치**: 신뢰·영수증·수수료 0%가 압도적입니다. 자격이 벽입니다. 지금 TeacherCan은 들어갈 수 없습니다.

### 국내 상시 후원

- **크티**: 후원 수수료 최저. 카드만 되는 점이 교사 UX의 약점입니다.
- **리틀리**: 후원이라는 말이 잘 맞습니다. 수수료는 중간입니다.
- **그로블**: 간편결제+정기결제가 가장 TeacherCan답습니다. "상품"으로 포장해야 합니다.
- **래피드**: 그로블의 대안. 한도를 확인하세요.

### 캠페인

- **텀블벅 Start**: 수수료가 낮고 창작 톤이 맞습니다.
- **와디즈 후원·팬덤**: 개인 수수료 지원 기간이 있으면 매력적입니다. 일반 펀딩은 비쌉니다.

### 자체 구축

- **토스페이먼츠**: 브랜드와 데이터 소유. 사업자+개발 비용.
- **페이플**: 정기구독에 유리. 견적 필요.

### 즉시

- **카카오페이·토스 송금**: 수수료 0, 관리 0점에 가깝습니다.

## 13. TeacherCan 추천 로드맵

한 가지만 고르라고 하면 안 됩니다. 후원은 "지금 받을 수 있는가"와 "1년 뒤에도 굴러가는가"가 다른 문제입니다.

### 1단계 — 이번 달에 검증 (사업자 없이)

목표: 교사 10~50명이 실제로 돈을 내는지 본다.

1. 사이트에 **후원 랜딩**을 만든다. 어디에 쓰이는지(서버, 도메인, 기능 개발)를 적는다. 기부금공제가 안 된다는 점도 적는다.
2. 결제 후보는 둘 중 하나, 또는 병행합니다.
   - **간편결제·정기를 원하면 그로블**로 "월 후원 멤버십" 상품
   - **일회성 응원을 원하면 크티 후원 또는 리틀리 후원**
3. 보조로 카카오페이/토스 송금 버튼을 둘 수 있습니다. 다만 개인 계좌 노출과 집계 공백을 감수해야 합니다.
4. GitHub Sponsors는 푸터에 작게만 둡니다. 개발자용입니다.

이 단계에서 패트리온, Ko-fi, 투네이션은 넣지 않는 것을 권합니다. 교사 결제 허들만 커집니다.

### 2단계 — 캠페인 (필요할 때만)

큰 기능(예: 모바일 앱, 대규모 인프라)이 필요하면 텀블벅 Start 또는 와디즈 후원·팬덤으로 한 번 모읍니다. 상시 후원과 섞지 말고, "이번 목표 / 상시 운영"을 페이지에서 구분해 주세요.

### 3단계 — 자체 후원 페이지 (사업자 이후)

후원이 반복되면 사업자등록 후 토스페이먼츠(또는 페이플 빌링)로 `/sponsor`를 만듭니다.

- 일회성: 5,000 / 10,000 / 30,000원 + 자유 금액
- 정기: 월 3,000 / 5,000 / 10,000원
- 카카오페이·토스페이·카드
- 후원자 목록(선택 공개), 감사 메일, 현금영수증

이 단계가 되면 외부 플랫폼 수수료를 줄이고, TeacherCan 브랜드 안에서 결제가 끝납니다.

### 하지 말 것

- 해피빈/같이가치에 "일단 신청" — 자격 미달로 시간만 씁니다.
- 방송 도네이션 UI — 학교 서비스 신뢰가 깎입니다.
- 기부금영수증이 된다고 오해하게 쓰기 — 민원이 생깁니다.
- 대가 없는 대규모 공개 모금을 목표액 1천만 원 이상으로 키우기 — 기부금품법 검토가 먼저입니다.

## 14. 의사결정 체크리스트

도입 전에 팀에서 아래만 정해도 플랫폼이 거의 결정됩니다.

1. 지금 사업자등록이 있는가?
2. 일회성이 급한가, 매달 서버비가 급한가?
3. 카카오페이 없는 카드 결제여도 괜찮은가?
4. 후원 페이지를 TeacherCan 안에 두고 싶은가, 외부 링크여도 되는가?
5. 후원자에게 줄 최소한의 혜택(이름 표시, 실험실, 뉴스레터)이 있는가?
6. 연말정산 질문을 어떻게 안내할 것인가?

빠른 매핑:

- 사업자 없음 + 카카오페이 중요 → 그로블 또는 리틀리
- 사업자 없음 + 수수료 최소 + 일회성 → 크티 후원
- 사업자 있음 + 사이트 내 결제 → 토스페이먼츠
- 한 번 크게 모으기 → 텀블벅 Start / 와디즈 후원·팬덤
- 오늘 버튼만 → 카카오페이·토스 송금
